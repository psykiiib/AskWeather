Welcome to AskWeather

This is a Dockerized Java application that fetches weather data.

How to use:

Follow this guide to set up, build, and run the application on your local machine.

Prerequisites

Before we begin, we must verify your development environment. This project relies on Java and Maven.

  • Verify Java: Run java -version (Requires JDK 17+).
  • Verify Maven: Run mvn -version.

Step 1: Get the Code

git clone https://github.com/psykiiib/AskWeather.git
cd AskWeather

Step 2: Configure the API Key

Crucial Step: The application requires an OpenWeatherMap API key to fetch real data.

  • Open src/main/java/com/weatherapp/WeatherService.java.
  • Replace the placeholder apiKey with your actual key.

Step 3: Build the Project

Run the following command to download dependencies and compile:

mvn clean install

Step 4: Run the Application

Start the interactive mode:

mvn exec:java

Step 5: Fetch Weather Data

Once running, enter a city name when prompted:

Enter the city for weather information:
> Paris
Weather in Paris: 5.92°C

Troubleshooting

  • "Failed to retrieve weather data": Check your API Key in WeatherService.java.
  • "mvn command not found": Ensure Maven is installed and in your system PATH.
